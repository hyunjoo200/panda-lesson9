# 중국어 탐험대 · 9차시 — 판다의 야시장 먹방 🏮

빨간 등불이 켜진 중국 야시장 길을 판다가 걸어가며 가게 7곳에 들러요. (5~6분, 문제 8개)
가게 앞에 서면 점원이 **你想吃什么？**(음료 가게는 你想喝什么？)라고 묻고 문제가 떠요.
맞히면 판다가 그 음식을 냠냠 먹고 **很好吃！** 하며 배가 점점 나와요.
마지막에 집에서 엄마 판다가 **好吃吗？** 하고 물으면 很好吃！로 대답하고, 배부른 판다가 晚安! 하고 자러 가요.

## 조작
- ▶ / ◀ 버튼을 누르고 있으면 걸어요 (PC는 → ← 키). 가게를 눌러도 그 가게까지 걸어가요.
- 진열대의 **음식 사진**을 누르면 이름을 들을 수 있고, 처음 누를 때 별 +5 (모든 음식을 구경하게 하려는 장치).

## 가게와 문제
| 가게 | 문제 방식 | 내용 |
| --- | --- | --- |
| 🐰 饺子馆 만두 가게 | 주문 쪽지 사진 → 말 고르기 | 包子 (馒头·饺子와 구별) |
| 🐱 面馆 국수 가게 | 친구 주문 듣고 사진 고르기 | 我想吃炸酱面。 (+ 중국 짜장면 이야기) |
| 🐻 米饭 밥집 | **마음대로 고르기** → 문장 순서 | 米饭/炒饭 중 고르고 我 想 吃 ○○ |
| 🐯 火锅 훠궈·마라탕 | 확대 사진 맞히기 | 麻辣烫 (+ 지역마다 다른 맛) |
| 🦊 烤鸭店 오리구이 가게 | 추천 메뉴 듣고 사진 고르기 | 我想吃北京烤鸭。 |
| 🐹 糖葫芦 간식 가게 | 확대 사진 맞히기 | 糖葫芦 |
| 🐶 奶茶店 음료 가게 | **마음대로 고르기** → 吃/喝 고르기 | 我想喝○○。 |
| 🐼 판다네 집 | 대답 고르기 | 好吃吗？ → 很好吃！ |

마음대로 고르는 문제는 정답이 없고, 다음 단계(문장 만들기)만 채점해요. 선생님 화면에서 학생이 고른 음식을 볼 수 있어요.
